Mars Weather

Hey there!

This is a small side project dedicated to the weather on Mars. It initially started as a way to practice Python + Playwright automation, and over time picked up various unrelated functionality. Currently I work on cleaning it up: removing what doesn't belong and introducing new features.

Originally weather readings were pulled from the Centro de Astrobiología (CAB), which had a dedicated API endpoint. That endpoint has since been retired, so I switched to NASA's Planetary Data System archive of measurements from the REMS instrument on the Curiosity rover. NASA publishes new Curiosity data in batches about three times a year, so the latest readings are always several months behind. The archive's server also doesn't allow automated downloads, so I fetch the files by hand and then parse them.

The project's code is on GitHub → GitHub repository.
