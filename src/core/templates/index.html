Mars Weather

Hey there!

This is my small pet project dedicated to Mars weather, which was initially made to learn Python + Playwright automation and contained various unrelated functionality. Currently I work on cleaning it up from unrelated functionality and introducing new related features.

Previously weather data was pulled from CAB INTA-CSIC, which had a dedicated API endpoint. Currently that API seems to be deprecated, therefore I switched to the original data source - the Mars Science Laboratory REMS data bundle. It’s being updated very slowly, and the data is downloaded by hand (as the site doesn’t support robotic access) and parsed.

Project’s code can be found here → GitHub repository.
